## Как запустить ноутбуки

Нужен Python 3.10+.

```bash
git clone https://github.com/gavnukkk97/itmo-product-analytics.git
```

```bash
cd itmo-product-analytics
```

```bash
pip install -r практика/requirements.txt
```

```bash
jupyter lab
```

Откройте ноутбук из папки `материалы/` нужной лекции: путь к базе строится от папки ноутбука. Подробнее — в [`практика/README.md`](практика/README.md).
