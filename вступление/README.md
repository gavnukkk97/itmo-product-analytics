# Вступительная лекция («лекция 0»)

**«Что делает аналитику полезной? И как сделать её ещё полезнее»** — 23 слайда, ~40–60 минут.

Вводная перед неделей 1: кто такой аналитик, зачем бизнесу аналитика (данные → знание → решения),
на каких этапах продукта она живёт, цели компаний, «о чём мечтают аналитические команды» и челлендж аудитории.

- `Преза-вступление.pptx` — исходник (45 МБ, с картинками)
- [`pdf/intro-lecture.pdf`](../pdf/intro-lecture.pdf) — версия для просмотра и печати

> ⚠️ PDF-файлы для просмотра на GitHub должны лежать по ASCII-путям (папка `pdf/`, латинские имена):
> вьювер GitHub не рендерит PDF из путей с кириллицей. Исходники pptx можно держать где угодно.
>
> Материал из курса ВШЭ по продуктовой аналитике; для ИТМО стоит обновить слайд «Про себя»
> и привязать примеры к сквозному продукту курса (маркетплейс «Лукошко»).
> Стыковка с неделей 1: вступление заканчивается «аналитика — это про решения», неделя 1 начинает
> с «какой вопрос мы вообще решаем» — можно читать подряд как один блок.
