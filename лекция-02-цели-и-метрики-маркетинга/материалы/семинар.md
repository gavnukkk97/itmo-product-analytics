# Семинар 2. Когорты, LTV и юнит-экономика в сегментах — ноутбук

**90 минут · онлайн, сессионные комнаты по 4–5 человек** · ноутбук [`семинар-02.ipynb`](семинар-02.ipynb)

Нужно заранее: `pip install -r практика/requirements.txt` (duckdb, pandas, matplotlib, statsmodels) и база
`практика/data/lukoshko.duckdb` (лежит в репозитории). Ноутбук читает базу только на чтение; выполняется целиком примерно за 20 секунд.
Ноутбук лежит в `лекция-02-цели-и-метрики-маркетинга/материалы/`; запускайте его из этой папки — путь к базе строится от неё
(`parents[1] / "практика"`, то есть `практика/` в корне репозитория).

## План

| Мин | Что | Формат |
|---:|---|---|
| 0–5 | Разминка: юнит заказа на данных против паспорта (скидка 5%, возврат) | все вместе |
| 5–25 | Часть 1. Когортная матрица, недозревшие ячейки, удержание по каналам, сессии против заказов | комнаты |
| 25–45 | Часть 2. Провал когорты «Чёрной пятницы»: состав или механика | комнаты |
| 45–50 | Сверка: три числа от каждой комнаты в общую таблицу | все вместе |
| 50–75 | Часть 3. LTV12, LTV/CAC и payback: «в среднем» → в сегментах, решение по CPA-сетям | комнаты |
| 75–85 | Часть 4. Прогноз LTV и стресс-тест «CAC +20%» | комнаты |
| 85–90 | Две комнаты зачитывают memo директору по маркетингу | все вместе |

**Треки.** Базовый — готовые ячейки и вопросы. Глубокий — вопросы со значком 🔵: rolling retention, разложение разницы
маржи на состав и «внутри сегментов», бутстреп LTV/CAC, градиентный бустинг вместо регрессии. Сначала пишут сами, потом сверяются.
