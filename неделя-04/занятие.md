# Неделя 4. Занятие — ноутбук: «в среднем» против «в сегментах»

**90 минут · Python/pandas · данные: `синтетика/orders.csv` + `синтетика/users.csv`**
**Цель: посчитать юнит-экономику так, чтобы решение разворачивалось на сегментах, и вшить
прогноз LTV в таблицу экономики вместо «оптимизации модели».**

## Данные

- `users.csv` — `user_id, reg_date, channel, promo_hunter, bf_cohort, activated_7d`.
- `orders.csv` — `order_id, user_id, order_date, gmv, margin, items, is_first_order`.
- CAC по каналам взять из таблицы в `00-сквозной-продукт.md` (это «внутренние данные маркетинга»).

### 1. Юнит «в среднем» (15 мин)

1. Маржа на заказ (средняя, медианная), заказов на покупателя, LTV12 по когортам регистрации.
2. CAC blended из таблицы каналов (посчитать: суммарный расход / суммарные новые платные
   пользователи; органика — без media-расходов).
3. Payback и LTV/CAC. Сверить с каноническими числами (±разброс выборки — обсудить, почему).

### 2. Юнит в сегментах (20 мин)

1. Присоединить к заказам `channel` и `promo_hunter`. LTV12 по 7 каналам.
2. Внутри CPA и social — разрез по `promo_hunter`: LTV promo-охотников отрицательный
   (скидки съедают маржу), обычных — нормальный.
3. Кривые накопленной маржи когорты по месяцам для 3 каналов: у кого плато, кто ещё растёт.

### 3. Решение, которое разворачивается (15 мин)

Собрать таблицу решений:

| Сегмент | LTV12 | CAC | LTV/CAC | Вердикт «в среднем» → «в сегменте» |
|---|---|---|---|---|
| CPA, обычные | ~1 900 ₽ | 1 400 ₽ | 1,4 | «слабый» → можно докручивать офферы |
| CPA, promo-охотники | ≈ 0 ₽ или минус | 1 400 ₽ | ≪1 | «слабый» → **выключить**, это не трафик, а утечка |
| Organic | ~2 800 ₽ | ~0 | ∞ | инвестировать в контент/SEO-команду |
| Influencer | ~2 300 ₽ | 1 900 ₽ | 1,2 | наивно «слабый» — вопрос атрибуции (мост к неделе 6) |

Обсуждение: какой вердикт разные люди примут, глядя только на среднее? (CFO урежет всё,
CMO скажет «у нас средний LTV/CAC 3,0 — всё отлично».)

### 4. Простая LTV-модель и её место (20 мин)

1. Обучить наивную регрессию: LTV3м (фактическая маржа первых 90 дней) → LTV12.
   Сплит по времени (когорты до мая — train, после — test). Посмотреть ошибки на краях
   (самые дорогие 1% и нулевые 30%): MAE на краях ×5–10 от среднего.
2. Вопрос залу: как использовать эту модель, чтобы **не повторить** ошибку «lookalike от
   высокого LTV»? Эталон: (а) оценка «потолка» сегментов, (б) выявление сегментов с быстрым
   payback для реинвестирования, (в) вход в таблицу экономики канала, (г) НЕ таргетинг «высокого LTV».

### 5. Стресс-тест (10 мин)

В таблице каналов поднять CAC платных каналов на 20% (аукцион подорожал):
- какие каналы выпадают из «окупаемых» первыми?
- на сколько должен вырасти LTV (частота/чек/удержание), чтобы сохранить текущую структуру
  закупки трафика? *(Проговорить: это уже вопросы продукту, а не маркетингу — экономика
  связывает недели 2 и 5.)*

## Что должно остаться в головах

1. Средняя юнит-экономика — витрина; решения живут в сегментах.
2. Сегмент «promo-охотники из CPA» — главный пример недели: выглядит как трафик, является убытком.
3. LTV-модель: forecast для таблицы экономики, не для таргетинга.
4. Payback ≠ LTV/CAC: касса и слайд — разные документы.
