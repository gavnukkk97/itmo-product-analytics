# Практика: учебная база «Лукошко»

📺 [Записи лекций](https://www.youtube.com/playlist?list=PLPlYipDKg8po) · ⬅️ [Все лекции](../README.md)

Все семинары курса идут на одной учебной базе — маркетплейсе «Лукошко» ([паспорт](../сквозной-продукт-лукошко.md)).
База — один файл DuckDB [`data/lukoshko.duckdb`](data/lukoshko.duckdb): работает локально, без серверов.
Данные учебные и детерминированные: у всех студентов получатся одни и те же числа.

База пополняется таблицами по мере выхода тем курса. Чтобы получить новую версию, сделайте `git pull`.

## Установка

```bash
pip install -r практика/requirements.txt
```

Ноутбуки семинаров лежат в `лекция-NN-…/материалы/`. Запускайте их из этой папки (так по умолчанию делает Jupyter):
путь к базе строится как `parents[1] / "практика"` от папки ноутбука, то есть ведёт в эту папку.

## Как открыть базу

Из Python:

```python
import duckdb
con = duckdb.connect("практика/data/lukoshko.duckdb", read_only=True)
con.sql("SELECT * FROM mart.orders LIMIT 5").df()
```

Без Python — в [DBeaver](https://dbeaver.io/) (драйвер DuckDB) или в консоли [DuckDB CLI](https://duckdb.org/docs/installation/).

## Что в базе сейчас

Выборка — 80 000 новых пользователей «Лукошко» за 18 месяцев (март 2025 — август 2026), ≈ 222 тыс. заказов.

| Таблица | Зерно | Строк | Что внутри | Семинар |
|---|---|---:|---|---|
| `mart.users` | пользователь | 80 000 | дата регистрации, канал привлечения, платформа, зона доставки, CRM-сегмент | 2 |
| `mart.orders` | заказ | 221 823 | GMV, доход платформы по строкам (комиссия, фронт-маржа 1P, доставка), логистика, промо, эквайринг, возвраты, CM заказа | 2, 3 |
| `mart.activity` | пользователь × день | 1,77 млн | дни, когда пользователь заходил в приложение | 2 |
| `raw.events` | событие | 1,31 млн | сырой лог продуктовых событий за 8 недель (16.02–12.04.2026) — в том виде, в каком он приходит из трекинга | 3 |
| `raw.orders` | заказ | 221 823 | заказы из учётной системы, без денег платформы | 3 |
| `meta.scale` | параметр | 3 | коэффициент перевода выборки в масштаб бизнеса | 2 |

**Масштаб.** Чтобы перевести число из выборки в масштаб бизнеса из паспорта, умножайте на
`SELECT value FROM meta.scale WHERE param = 'scale_factor'` (≈ 159).

**Сырые данные — сырые.** `raw.*` — это то, что пришло из источника, без чистки. Прежде чем считать по ним метрики,
проверьте, можно ли им доверять: этому посвящён семинар 3.
